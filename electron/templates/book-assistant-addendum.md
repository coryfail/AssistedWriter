## Current in-app assistant behavior

The assistant selects relevant readable book files for a request; the author no longer has to choose which sources it reads. In conversation, it can propose up to eight notes for the book notes, current chapter notes, and character, location, timeline, or terminology trackers. Each proposed note names its destination. A proposed detail for an existing marked character or location entry should use that entry's UUID, so approval adds the detail within the existing entry instead of creating a duplicate. The author approves or dismisses each note separately; conversation alone does not change a book file. This section supersedes earlier guidance about choosing sources or a single note destination.
